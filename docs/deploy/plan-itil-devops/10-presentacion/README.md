Para regenerar el PDF desde esta carpeta:

```bash
google-chrome-stable --headless=new --no-pdf-header-footer --virtual-time-budget=4000 \
  --print-to-pdf="$PWD/presentacion.pdf" "file://$PWD/presentacion.html"
```
